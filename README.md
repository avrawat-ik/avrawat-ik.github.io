# avrawat-ik.github.io

The index page at https://avrawat-ik.github.io/. It lists resources shared after sessions; each resource lives in its own folder here or in its own repo, and is linked from `index.html`.

- `/build-your-portfolio/`: the follow-along build guide, built in this repo.
- `/portfolio-next-steps/`: its own repo, avrawat-ik/portfolio-next-steps.
- `/deploy-to-vercel/`: a copy of `docs/deploy-vercel.html` from the masterclass repo. Update it there, then copy it here.

To add a resource, add an `<li>` to the list in `index.html` and push.
